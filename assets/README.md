# تجهيز الأصول

هذا المرجع للتنزيل والفحص المحلي فقط. طريقة استخدام المهارة دون أدوات تنفيذ في [USAGE.md](../USAGE.md).
قواعد التصميم في [SKILL.md](../SKILL.md) ومراجعه، وبيانات الملفات في [catalog.json](catalog.json).

الأصول المسجلة `bundled` موجودة في `assets/identity` نسبة إلى مجلد المهارة. اختر المجموعة اللازمة
للمهمة من الفهرس؛ يحدد حقل `availability` ما هو مرفق وما يُنزَّل عند الحاجة.
في الحزمة الخفيفة، تشير `repository_download` إلى أصل إضافي في المستودع، وتحدد `source_url`
رابطه المثبّت على إصدار الحزمة. نزّله عند الحاجة إلى مساره المسجل، ثم طابق الحجم والبصمة.
تبقى نسخة المصدر الكاملة مرجع الأصول، وتحتفظ الحزمة الخفيفة بالقوالب الجاهزة وأربعة شعارات PNG
وأوزان DIN الثلاثة. معاينات القوالب في `previews`، وقيم الشاشة المشتقة في `digital-tokens.json`.

## دليل الهوية

بيانات الأصل الموثق ورابطه وحجمه وبصمته في [downloads.json](downloads.json). يشير الرابط إلى
الإصدار الذي نُشر فيه الأصل، ويظل صالحاً عبر تحديثات التعليمات. يمكن تنزيله يدوياً إلى المسار
المحدد في السجل، أو تشغيل الآتي من جذر المهارة عند توفر Python 3 واتصال بالشبكة:

```sh
python scripts/prepare_assets.py
```

يفحص الأمر النسخة الموجودة، وينزّل الدليل عند غيابه، ويرفض استبدال ملف مختلف. لا تحتاج مهمة نصية
بسيطة إلى تنزيل الدليل. لا ينزّل الأمر أصولاً أخرى ولا يثبّت خطوطاً.

## الفحص الاختياري

```sh
python scripts/preflight.py
```

هذا فحص توافر وتواقيع ملفات أساسية فقط؛ القالب المختار وتحميل الخط والتصيير النهائي تُفحص بحسب
المهمة. وجود الخطوط في المجلد لا يحمّلها في تطبيق التحرير تلقائياً.

لأدوات الحزمة، ترتيب جذر الأصول هو `--root` ثم `IDENTITY_DESIGN_ROOT` ثم `assets/identity` المرفق،
على كل الأنظمة. ترتيب جذر الخطوط في الفاحص هو `--font-root` ثم `IDENTITY_DESIGN_FONT_ROOT` ثم
مجلد `الخطوط -Fonts` داخل جذر الأصول المختار. أي مسار صريح غير صالح يُظهر خطأ ولا يستبدل بصمت.
تعرض `--help` الخيارات المتاحة؛ لا حاجة إلى تعديل إعدادات الجهاز إذا كانت الأصول المرفقة مناسبة.

## التحقق عند إصدار تحديث

من جذر المهارة، شغّل:

```sh
python -m unittest discover -s tests -v
python scripts/validate_package.py
```

يتحقق المدقق من الملفات الفعلية وأحجامها وبصماتها، واتساق الفهارس وروابط Markdown المحلية
إلى الملفات. يسمح بغياب الدليل والأصول الاختيارية المعلنة، ويفحصها إذا توفرت. لا يفحص روابط
الويب أو عناوين الأقسام أو جودة التصيير. فحص سلوك المساعد موثق مستقلاً في [التقييم](../evals/README.md).

بعد تعديل مقصود، حدّث سجلات الأصول المتأثرة في الفهرس، وأضف ملفات الإصدار إلى Git، ثم نفّذ
`python scripts/validate_package.py --write-manifest` لتجديد سجل التسليم والتحقق منه. يبقى
سجل المصدر والبصمات الأصلية محفوظاً؛ اختلاف بصمة أصل محفوظ خطأ يحتاج تفسيراً وتصحيحاً.

لإنشاء ZIP خفيف من المصدر نفسه بعد نجاح التحقق:

```sh
python scripts/build_lite.py --output ../identity-design-lite-v1.5.0.zip
```

يرفض المنشئ استبدال ZIP موجود، ويثبت روابط الأصول الإضافية على نسخة بيان التسليم. فك الحزمة
وشغّل المدقق من داخل مجلد `identity-design` قبل نشرها. لا تحتاج إلى إعادة رفع دليل الهوية
الكبير غير المتغير.
