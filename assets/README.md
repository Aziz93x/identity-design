# الأصول المرفقة

تُكتشف الأصول تلقائياً في `assets/identity` نسبة إلى مجلد المهارة. لا يحتاج الزميل إلى مسار الجهاز الذي أُعدت عليه الحزمة.

يصف `catalog.json` الملفات الموجودة ودور كل مجموعة، ويميز القالب الجاهز من المصادر الأصلية التي تحتاج تهيئة. الشعارات والعناصر وملفات التصميم الأصلية محفوظة بأسمائها وبصماتها؛ تعليمات التشغيل المصاحبة منقحة لتعمل خارج الجهاز الأصلي.

## دليل الهوية الكبير

يحفظ إصدار المستودع نسخة PDF أخف من الدليل الأصلي، دون خفض دقة الصور. يستدعيها المساعد الآتي ويضعها تلقائياً في مجلد الأصول بعد التحقق من الحجم والبصمة:

```powershell
python scripts/prepare_assets.py
```

يعمل الأمر من جذر المهارة. التنزيل مرة واحدة، ويحتاج اتصالاً بالشبكة في المرة الأولى فقط. بيانات الملف وعنوانه وبصمته في `downloads.json`. يتوقف المساعد عند وجود ملف مختلف بدلاً من استبداله بصمت.

## الخطوط

ملفات DIN غير مرفقة بالنشر العام حالياً بسبب نص منع التوزيع في ترخيصها. تُقرأ من حزمة المستخدم المرخصة، وتفحص المهارة ملفاتها قبل التصميم. لا يُستبدل خط عربي بخط مختلف بصمت. انظر تعليمات إعداد الخطوط في README الرئيسي ونتيجة أداة الفحص.

## القوالب الأصلية

تتضمن بعض الأصول الأصلية شعارات المؤسسة العامة أو بيانات أمثلة وجهات ناشرة قديمة. تستعمل المهارة هذه الملفات مصادر للتصميم، ثم تهيئ نسخة العمل بشعار الكلية والمحتوى الفعلي وتفحصها قبل التسليم. وجود الملف في الحزمة لا يعني اعتماد بياناته المؤقتة أو أن تحريره داخل Adobe اختُبر.

حقوق الشعارات والخطوط والقوالب والدليل محفوظة لأصحابها. ترخيص MIT للكود والتعليمات لا يعيد ترخيص الأصول الخارجية.
