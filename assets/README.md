# الأصول المرفقة

تُكتشف الأصول تلقائياً في `assets/identity` نسبة إلى مجلد المهارة. لا يحتاج الزميل إلى مسار الجهاز الذي أُعدت عليه الحزمة.

يصف `catalog.json` الملفات الموجودة ودور كل مجموعة، ويميز القالب الجاهز من المصادر الأصلية التي تحتاج تهيئة. الشعارات والعناصر وملفات التصميم الأصلية محفوظة بأسمائها وبصماتها؛ تعليمات التشغيل المصاحبة منقحة لتعمل خارج الجهاز الأصلي.

## دليل الهوية الكبير

يحفظ إصدار المستودع نسخة PDF أخف من الدليل الأصلي، دون خفض دقة الصور. يستدعيها المساعد الآتي ويضعها تلقائياً في مجلد الأصول بعد التحقق من الحجم والبصمة:

```powershell
python scripts/prepare_assets.py
```

يعمل الأمر من جذر المهارة. إذا كان الدليل موجوداً وبصمته مطابقة، يتحقق منه دون اتصال بالشبكة؛ وإلا يحتاج اتصالاً لتنزيله مرة واحدة عند غيابه. بيانات الملف وعنوانه وبصمته في `downloads.json`. يتوقف المساعد عند وجود ملف مختلف بدلاً من استبداله بصمت.

## الخطوط

ملفات الخطوط الأصلية العشرة، ومنها ملفات DIN، مرفقة في `assets/identity/الخطوط -Fonts` دون تغيير ملفاتها أو تراخيصها أو بيانات نسبتها. تُكتشف تلقائياً من جذر الأصول المختار، وتفحص المهارة الملفات الأساسية قبل التصميم. من جذر المهارة، شغّل:

```powershell
python scripts/preflight.py
```

يبقى `--font-root` أو `IDENTITY_DESIGN_FONT_ROOT` خياراً لاستعمال مجلد خطوط خارجي بدلاً من المرفق. لا يُستبدل خط عربي بخط مختلف بصمت. انظر تعليمات الجذور البديلة في README الرئيسي ونتيجة أداة الفحص.

## القوالب الأصلية

تتضمن بعض الأصول الأصلية شعارات المؤسسة العامة أو بيانات أمثلة وجهات ناشرة قديمة. تستعمل المهارة هذه الملفات مصادر للتصميم، ثم تهيئ نسخة العمل بشعار الكلية والمحتوى الفعلي وتفحصها قبل التسليم. وجود الملف في الحزمة لا يعني اعتماد بياناته المؤقتة أو أن تحريره داخل Adobe اختُبر.

حقوق الشعارات والخطوط والقوالب والدليل وتراخيصها الأصلية وبيانات نسبتها محفوظة لأصحابها. يخص ترخيص MIT الكود والتعليمات والوثائق المؤلَّفة للمشروع فقط، ولا يعيد ترخيص الأصول المرفقة.
