# شعارات الكلية التقنية بالدائر

تحتوي الحزمة على أربع نسخ من الشعار المركب: أفقية وعمودية، ملونة وبيضاء. اسم الكلية جزء من كل ملف.

| المجلد | الاستخدام |
|---|---|
| `PNG/` | الصور الشفافة بالأبعاد الأصلية |
| `PNG-cropped/` | نسخ تقلل الهامش الخارجي دون قص الرسم أو تكبيره |
| `SVG-outlined/` | اسم الكلية محوّل إلى مسارات ولا يحتاج إلى خط مثبت |
| `SVG-editable/` | اسم الكلية نص قابل للتحرير ويحتاج DIN Next LT Arabic Regular |

| النسخة | أبعاد PNG الأصلية |
|---|---|
| `horizontal-color` | 566 × 206 |
| `horizontal-white` | 2480 × 1004 |
| `vertical-color` | 2953 × 2953 |
| `vertical-white` | 2953 × 2953 |

اختر الملون للخلفيات الفاتحة والأبيض للخلفيات الداكنة. حافظ على المساحة الآمنة خارج المركب كله، حتى عند استخدام النسخ المقصوصة. تفاصيل القياس موثقة في `references/visual-rules.md` في جذر المهارة.

ملفات SVG تحتوي صورة PNG مؤسسية مضمّنة، فلا تُعد رسوماً متجهية كاملة ولا تمنح دقة أعلى من المصدر. يُفضل PNG أو SVG-outlined عند تسليم PowerPoint؛ سجل الفحص التاريخي يشير إلى اختلاف عرض اسم الكلية في SVG-editable في PowerPoint رغم سلامة النص.

حُفظت ملفات الصور وSVG كما وردت في الحزمة المحلية وبالبصمات نفسها. هذا المستودع لا يتضمن معاينات `previews/` ولا ملفات QA التاريخية. حقوق الأصول لأصحابها، وهي حزمة تطبيق للتكوين الذي اختاره صاحب الطلب وليست إصداراً مؤسسياً جديداً.
