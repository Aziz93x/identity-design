# identity-design

مهارة لتطبيق هوية **الكلية التقنية بالدائر** على العروض والمستندات والمواد الإعلامية، وكتابة نصوصها العربية الرسمية. بُنيت على تحليل حزمة الهوية المحلية ومراجعة مصادرها، مع فصل قواعد الدليل عن اختيارات المستخدم والملاحظات الفنية.

تحتوي الحزمة على تعليمات المهارة وسبعة مراجع وأصول تصميم مرفقة تُكتشف تلقائياً، مع أدوات إعداد وفحص. تعمل مباشرة كمهارة محلية، ولا تتطلب خادم MCP أو خدمة مدفوعة. يحتاج إنتاج الملفات إلى أدوات التحرير المناسبة المتاحة في بيئة المستخدم.

## التثبيت في Codex

يمكن تنزيل [الحزمة الكاملة من الإصدار](https://github.com/Aziz93x/identity-design/releases/latest)، وتشمل المهارة والأصول والخطوط الأصلية ودليل الهوية. فك الضغط وضع مجلد `identity-design` في مجلد مهارات Codex؛ تُكتشف الأصول والخطوط من موقع التثبيت تلقائياً.

يمكن طلب التثبيت من Codex بهذه العبارة:

> ثبّت مهارة identity-design من المستودع https://github.com/Aziz93x/identity-design، من جذر المستودع، باسم identity-design.

أو نفّذ الأوامر التالية في PowerShell بعد تثبيت Git:

```powershell
$skillBase = if ($env:CODEX_HOME) { Join-Path $env:CODEX_HOME 'skills' } else { Join-Path $env:USERPROFILE '.codex/skills' }
$skillTarget = Join-Path $skillBase 'identity-design'
if (Test-Path -LiteralPath $skillTarget) { throw 'مجلد المهارة موجود. احتفظ بنسختك الحالية وراجعها قبل التحديث.' }
New-Item -ItemType Directory -Path $skillBase -Force | Out-Null
git clone https://github.com/Aziz93x/identity-design.git $skillTarget
```

تكون المهارة متاحة بدءاً من الرسالة التالية. يمكن التحقق من التثبيت بوجود `SKILL.md` داخل مجلد `identity-design`.

## تجهيز الأصول

الأصول المرفقة موجودة في `assets/identity` وتعمل من أي موقع تُثبّت فيه المهارة. يتضمن [فهرس الأصول](assets/catalog.json) الشعارات والعناصر والألوان والقوالب بحسب نوع المخرج، مع بيان المصادر التي تحتاج تهيئة. تشرح [صفحة الأصول](assets/README.md) حدودها وطريقة التعامل معها.

يوجد قالب جاهز من ست شرائح للعروض التدريبية المصوّرة: غلاف، محتوى نصي، صورة مع شرح، مقارنة، مثال بثلاثة مشاهد، وختام. النصوص قابلة للتحرير، ومساحات الصور مربعات قابلة للاستبدال بالصور وليست حقول إدراج بنقرة واحدة. تُملأ الحقول وتضبط الحركة بحسب المحتوى قبل التسليم.

من جذر المهارة، شغّل الأمر التالي باستخدام Python 3 للتحقق من دليل الهوية الموجود، أو تنزيله من إصدار المستودع إن كان غائباً. يتحقق المساعد من الحجم والبصمة، ويبقى الدليل محلياً بعد التنزيل الأول:

```powershell
python scripts/prepare_assets.py
```

تتضمن الحزمة ملفات الخطوط الأصلية العشرة، ومنها ملفات DIN، في `assets/identity/الخطوط -Fonts` دون تغيير ملفاتها أو تراخيصها أو بيانات نسبتها. تُكتشف تلقائياً، ولا يلزم تحديد مجلد خطوط خارجي للتشغيل المعتاد. افحص الأصول والخطوط المرفقة بالأمر:

```powershell
python scripts/preflight.py
```

يمكن اختيار مجلد خطوط خارجي بدلاً من المرفق عند الحاجة:

```powershell
python scripts/preflight.py --font-root 'D:\LicensedFonts'
```

أو حفظ موقع الخطوط الخارجي للمستخدم الحالي، ثم إعادة فتح Codex ليلتقط القيمة:

```powershell
[Environment]::SetEnvironmentVariable('IDENTITY_DESIGN_FONT_ROOT', 'D:\LicensedFonts', 'User')
```

يفحص المساعد ملفي `DINNextLTArabic-Regular-3.ttf` و`alfont_com_AlFont_com_DINNextLTArabic-Medium.ttf` ضمن الملفات الأساسية؛ ويُستخدم Light عندما تتطلبه المهمة. تفاصيل ملفات المصدر والأنماط في [خريطة الأصول](references/asset-map.md). أولوية الخطوط: `--font-root`، ثم `IDENTITY_DESIGN_FONT_ROOT`، ثم مجلد `الخطوط -Fonts` داخل جذر الأصول المختار. إذا كانت نسختك الخارجية تحمل أسماء ملفات مختلفة، وضّح مساراتها للمساعد ليتحقق من العائلة والنمط ويستخدمها دون تغيير المصدر.

إذا أردت استعمال حزمة أصول كاملة أخرى بدلاً من المرفقة، حدد موقعها في طلبك أو عيّن المتغير التالي، مع استبدال المسار بمجلدك الفعلي:

```powershell
[Environment]::SetEnvironmentVariable('IDENTITY_DESIGN_ROOT', 'D:\CollegeIdentity', 'User')
```

أعد فتح التطبيق بعد تغيير المتغير الدائم ليلتقط قيمته. أولوية الجذر: `--root`، ثم `IDENTITY_DESIGN_ROOT`، ثم الأصول المرفقة، ثم المسار التاريخي على Windows عند غياب الحزمة المرفقة. لا تنتقل الأداة إلى مسار بديل عند تحديد مسار غير صالح أو وجود حزمة ناقصة.

لتجهيز دليل الهوية وفحص حزمة الأصول البديلة من مجلد المهارة، استخدم الجذر نفسه في الأمرين:

```powershell
python scripts/prepare_assets.py --root 'D:\CollegeIdentity'
python scripts/preflight.py --root 'D:\CollegeIdentity'
```

يفحص المساعد تسعة ملفات أساسية دون تنزيلها أو نسخها أو تثبيت الخطوط. يختلف عن مساعد التجهيز الذي ينزّل الدليل الموثق فقط. نجاح الفحص يعني أن الملفات المطلوبة موجودة وقابلة للقراءة؛ تُراجع سلامة الخطوط والتصميم في المخرج النهائي. تُختار القوالب من الفهرس وتُفحص بحسب المهمة. التحرير النصي العادي لا يحتاج إلى تحميل الدليل أو الخطوط.

## الاستخدام

> استخدم $identity-design لإعداد عرض تعريفي للكلية التقنية بالدائر من الأصول المرفقة والقالب المناسب، والمحتوى في الملف المرفق.

> استخدم $identity-design لمراجعة هذا الإعلان العربي الرسمي للكلية، مع إبقائه نصاً فقط: [النص].

> استخدم $identity-design لمراجعة هذا العرض من حيث الشعار والخطوط والألوان واتجاه العربية، ثم أصلح المشكلات في نسخة جديدة.

تحافظ المهارة على الأصول، وتبدأ المخرجات المصممة من القالب الأصلي المناسب، وتستخدم الشعارات المركبة التي يظهر فيها اسم الكلية. تميّز المراجع بين الأصول المتجهية والنقطية، وتوضح قيود الخطوط وقيم الألوان ونتائج الفحص السابقة. لا تُطبّق هوية الكلية تلقائياً على أعمال جهة أخرى.

مسار العروض التدريبية المصوّرة مثبت في المهارة: حفظ المحتوى الأصلي، واختيار مواضع التصوير، وإضافة أمثلة مستقلة عند كثافة النص، ودمج الصور مع نصوص وعناصر قابلة للتحرير، ثم ضبط الحركة اليدوية ومراجعة PPTX وPDF النهائيين. يمكن طلبه بعبارة:

> استخدم $identity-design وطبّق مسار العرض التدريبي المصوّر على الملف المرفق، مع الحفاظ على المحتوى كاملاً وتسليم PPTX وPDF.
